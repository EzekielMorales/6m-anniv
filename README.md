# 🌕 Loy Krathong & 6-Month Anniversary ✨

A lightweight, interactive web experience celebrating Loy Krathong and a romantic 6-month anniversary, crafted in a paper cutout scrapbook aesthetic on lined notebook paper.

🔗 **Live Demo:** [https://ezekielmorales.github.io/6m-anniv/](https://ezekielmorales.github.io/6m-anniv/)

---

## 🌟 Features

- **🎨 Pure Vector Paper Cutout Art**: 100% procedural SVG paper-cut illustrations with realistic paper shadows and edges—featuring a Thai riverside village, temple, stupa, palm tree, and smiling moon.
- **🎋 3 Handcrafted Krathong Choices**:
  - Bread Krathong (กระทงขนมปัง)
  - Banana Leaf Krathong (กระทงใบตอง)
  - Coconut Shell Krathong (กระทงกะลามะพร้าว)
- **🕯️ Interactive Experience**:
  - Pick a Krathong from the scrapbook card deck.
  - Light the candle (`จุดเทียน`) with warm flickering flames and glowing aura.
  - Release into the water (`ลอยกระทง`) with animated drifting waves, drifting NPC krathongs, and floating sky lanterns.
- **🎆 Particle Text Fireworks**: Rockets burst into sparkling starry particles spelling romantic anniversary messages across the night sky:
  - *"รักนะมิ้ว"*
  - *"สุขสันต์วันครบรอบ 6 เดือน"*
- **💌 Scrapbook Love Letter & Polaroid Gallery**: Pinned with washi tape, containing a heartfelt anniversary note and an interactive polaroid photo frame with slide controls and dots to view your favorite photos.
- **🎵 Romantic Backing Track**: Embedded background music with a paper-styled toggle button (auto-starts on interaction).
- **📱 Fully Responsive**: Specially fine-tuned for smartphones (portrait mode) as well as desktop screens.

## 🚀 How to Run Locally

You can run this project locally using any simple HTTP server:

### Option 1: Python (Recommended)

Open your terminal or PowerShell in the project directory:

```bash
# Navigate to the project folder
cd t:\my-projects\6m-anniv

# Start the local server on port 8080
python -m http.server 8080
```

Then open your browser and navigate to:
👉 **[http://localhost:8080](http://localhost:8080)**

---

### Option 2: Node.js (`npx serve`)

If you have Node.js installed:

```bash
npx serve .
```

---

### Option 3: VS Code Live Server Extension

1. Open this folder in **VS Code**.
2. Right-click on `index.html`.
3. Select **"Open with Live Server"**.

---

## 🌐 Deployment (GitHub Pages)

This project has zero dependencies and runs natively in modern browsers:

1. Push this repository to GitHub.
2. In your GitHub repository, go to **Settings** > **Pages**.
3. Under **Build and deployment**:
   - Source: `Deploy from a branch`
   - Branch: `main` / folder: `/ (root)`
4. Click **Save**. Your site will be live within 1–2 minutes!
